🏭 Manufacturing Downtime Analysis

Analysis of productivity and downtime data from a soda bottling production line.

📌Overview
This project evaluates production efficiency using batch-level data including:
- Operator
- Product
- Start & End Time
- Downtime Duration
- Downtime Factors

🎯 Key Questions
- What is the current line efficiency?
- Are any operators underperforming?
- What are the leading causes of downtime?
- Do specific operators struggle with certain error types?

📊 Analysis Performed
- Line Efficiency = (Total Time − Downtime) / Total Time  
- Operator-wise performance comparison  
- Downtime Pareto analysis  
- Operator × Downtime factor breakdown  

🚀 Outcome
Identified major downtime drivers and operator-specific performance gaps to support targeted improvements and increased production efficiency.
